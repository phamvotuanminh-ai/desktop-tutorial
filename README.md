## 1. Mục tiêu đề tài
Xây dựng hệ thống web quản lý trung tâm tiếng Anh nhằm tối ưu hóa quy trình vận hành, hỗ trợ quản lý khóa học, lớp học, học viên, giáo viên, phụ huynh và quy trình đăng ký/thanh toán.

## 2. Các tác nhân chính (Actors)
- **Admin (Quản trị viên):** Quản lý hệ thống, tài khoản, lớp học, khóa học, doanh thu.
- **Teacher (Giáo viên):** Quản lý lịch dạy, điểm danh, nhập điểm, nhận xét học viên.
- **Student (Học viên):** Xem lịch học, bảng điểm, thông báo, đăng ký khóa học.
- **Parent (Phụ huynh):** Theo dõi tiến độ học tập, điểm danh và học phí của con em.
- **Guest (Khách vãng lai):** Xem thông tin khóa học, lịch khai giảng, đăng ký tư vấn.
- **System (Hệ thống tự động):** Tự động gửi thông báo, nhắc lịch học, sao lưu dữ liệu.
